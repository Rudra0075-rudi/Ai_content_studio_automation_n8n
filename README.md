# Ai_content_studio_automation_n8n
Designed and built a 71-node n8n automation pipeline integrating Gemini AI, Telegram Bot API, and Google Sheets to automate content ideation, multi-platform draft generation, scheduled publishing, and performance analytics — entirely on free-tier services.
AI Content Studio is a multi-platform content publishing pipeline with an analytics feedback loop, built as a single 71-node n8n workflow. The system manages the complete content lifecycle — from raw idea to published post to performance analysis — through a conversational Telegram bot interface. When a user sends an idea or URL, the pipeline uses Google Gemini 2.5 Flash to extract structured metadata including content type classification, key points, and hook generation. The draft generation engine runs four sequential AI calls — one long-form writer followed by three platform-specific repurposing agents for Twitter, LinkedIn, and Telegram — each passing through validation gates that enforce character limits and platform conventions. A cron-based scheduler checks every 15 minutes for due posts and auto-publishes to Telegram channels or delivers copy-paste-ready content via DM for platforms without free API access. The analytics module collects engagement metrics and runs weekly AI-powered trend analysis, creating a feedback loop where content performance data informs future topic selection. The entire stack runs on free-tier services: n8n Community Edition for orchestration, Google Gemini API for AI reasoning, Google Sheets as a state-driven database tracking content through a five-stage lifecycle (IDEA → DRAFTED → REVIEWED → SCHEDULED → PUBLISHED), and Telegram Bot API for input, output, notifications, and publishing. Key engineering decisions include sequential AI execution to avoid rate limits with graceful error handling, a single-workflow architecture eliminating inter-workflow webhook complexity, and platform-specific output validation ensuring every generated draft meets its target platform's constraints before storage.
